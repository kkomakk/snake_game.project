# 🐍 Snake Game (C++)

## 📘 프로젝트 개요
이 프로젝트는 **C++ 콘솔 환경에서 구현한 Snake Game**으로,  
단순한 게임 개발을 넘어 **실시간 입력 처리, 충돌 판정, 프레임 동기화 구조 설계**를 목표로 제작되었습니다.  
팀 내에서는 **게임 로직과 충돌 판정 모듈**을 맡아, 각자 구현한 입력·렌더링 모듈과의 **데이터 일관성 유지**를 중점으로 개발했습니다.

---

## ⚙️ 기술 스택
| 구분 | 내용 |
|------|------|
| 언어 | C++17 |
| 개발 환경 | Visual Studio / g++ (Windows/Linux 호환) |
| 주요 기능 | 실시간 입력 처리, 벽/자신과의 충돌 판정, 점수 시스템, 속도 조절, 게임 루프 구조화 |

---

## 🕹️ 주요 기능

### 1. 실시간 입력 처리
- `getch()`와 논블로킹 입력 방식을 사용하여 지연 없는 방향 전환 구현  
- 반대 방향 즉시 입력 방지 로직으로 부드러운 이동 유지  

### 2. 충돌 판정
- Snake 머리의 좌표가 벽이나 자신의 몸과 일치하면 게임 종료  
- 각 프레임마다 좌표 리스트를 업데이트하여 **충돌 감지 효율 최적화**  

### 3. 아이템 및 점수 시스템
- 맵 내 랜덤한 위치에 음식 생성  
- Snake가 음식 좌표에 닿으면 길이 증가 및 점수 +1  

### 4. 게임 루프 구조
- 일정한 FPS를 유지하며 루프 실행  
- `update()`, `render()`, `input()` 함수로 역할 분리
